# تقنيات برمجية متقدمة (Advanced Programming Techniques)

هذا المستودع مخصص لمادة **تقنيات برمجية متقدمة**. يحتوي على مجموعة من الاختبارات (Quizzes)، الملاحظات، والأمثلة البرمجية التي تغطي المواضيع المتقدمة في البرمجة.

## محتويات المستودع
- **[الاختبارات (Quizzes)](./Quizzes/):** أسئلة تدريبية على مواضيع مختلفة مثل البرمجة كائنية التوجه المتقدمة، أنماط التصميم، والبرمجة الوظيفية.
- **[المصادر (Resources)](./Resources/):** روابط ومستندات مفيدة للمادة.
- **[أمثلة برمجية (Examples)](./Examples/):** كود مصدري يشرح بعض التقنيات المتقدمة.

## المواضيع المغطاة
1. البرمجة كائنية التوجه المتقدمة (Advanced OOP).
2. أنماط التصميم (Design Patterns).
3. البرمجة الوظيفية (Functional Programming).
4. إدارة الذاكرة ومعالجة الأخطاء (Memory Management & Exception Handling).
5. البرمجة المتزامنة (Concurrent Programming).

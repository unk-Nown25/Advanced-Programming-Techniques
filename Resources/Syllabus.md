# خطة مقرر تقنيات برمجية متقدمة

توضح الجداول التالية المواضيع الرئيسية التي يتم تناولها في هذا المقرر وتوزيعها الزمني المقترح.

| الأسبوع | الموضوع الرئيسي | التفاصيل |
| :--- | :--- | :--- |
| 1-2 | مراجعة OOP المتقدمة | الوراثة، التعددية، التجريد، والواجهات بشكل معمق. |
| 3-4 | التعامل مع الاستثناءات والذاكرة | Exception Handling, Garbage Collection, Stack vs Heap. |
| 5-7 | أنماط التصميم (Design Patterns) | Creational, Structural, and Behavioral Patterns. |
| 8-9 | البرمجة الوظيفية (Functional) | Lambda Expressions, Streams API, Higher-order functions. |
| 10-12 | البرمجة المتزامنة (Concurrency) | Threads, Synchronization, Deadlocks, Parallel Processing. |
| 13-14 | تقنيات الويب المتقدمة | RESTful APIs, Dependency Injection, Frameworks. |
